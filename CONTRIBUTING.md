# Участие в разработке Bin11

Спасибо за интерес к улучшению Bin11!

## Сообщение об ошибках

Откройте [issue](../../issues) и опишите:
- Чёткое описание проблемы
- Шаги для воспроизведения
- Вашу версию Windows и версию .NET (если знаете)
- Содержимое `%AppData%\Bin11\log.txt`, если приложение упало

## Предложение идей

Откройте [issue](../../issues) с меткой `enhancement` и опишите, что хотелось бы увидеть.

## Pull Request'ы

1. Сделайте форк репозитория и создайте ветку от `main`.
2. Внесите свои изменения.
3. Убедитесь, что проект собирается без ошибок.
4. Откройте PR с чётким описанием того, что вы изменили и почему.

# Contributing to Bin11

Thanks for your interest in improving Bin11!

## Reporting Bugs
Please open an [issue](../../issues) and include:
- A clear description of the problem
- Steps to reproduce
- Your Windows version and .NET version (if known)
- The contents of `%AppData%\Bin11\log.txt` if the app crashed

## Suggesting Features
Open an [issue](../../issues) with the `enhancement` label and describe what you'd like to see.

## Pull Requests
1. Fork the repo and create a branch from `main`.
2. Make your changes.
3. Ensure the project builds without errors.
4. Open a PR with a clear description of what you changed and why.
